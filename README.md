# Mcqueen Studio Automotivo

Site institucional em Astro para a Mcqueen Studio Automotivo, com páginas de serviços, galeria interativa, comparador antes/depois, SEO técnico e CTAs contextuais para WhatsApp.

## Rodar localmente

```bash
npm install
npm run dev
```

O servidor de desenvolvimento usa a porta `3000`. Para gerar a versão estática:

```bash
npm run build
```

Reconfirmar o endereço do Google Business Profile, nota/quantidade de avaliações, disponibilidade de cada serviço, marcas eventualmente citadas e horários. As mensagens de WhatsApp geradas pelo site começam com: `Olá! Vim pelo site da Mcqueen Studio...`.
